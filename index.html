📱 문제의식 ① 스마트폰 과다 노출

청소년의 97%가 스마트폰을 사용하며, 주당 사용 시간은 평균 12시간에 이릅니다. 전체 청소년 중 약 40%가 과의존 위험군에 분류되어 적극적인 관찰이 필요합니다.

😴 문제의식 ② 수면 감소와 생체 주기 교란

스마트폰 과다 사용은 심각한 수면 시간 단축 및 생체리듬 불균형을 야기하며, 신체 면역 저하 및 위생 관리 소홀로 이어져 **구강 건강 악화를 초래**합니다.

🦷 문제의식 ③ 자가 예측 서비스의 부재

청소년 스스로 자가 진단을 수행하고 예측 결과를 기반으로 올바른 수칙 가이드 및 실시간 의료기관(치과) 연계까지 지원하는 서비스 흐름이 공백 상태였습니다.

💡 ROC-AUC 0.64~0.65 — 이 수치의 의미

본 프로젝트는 임상 검사가 아닌 자가보고(Self-report) 기반 국가 설문조사 데이터를 활용합니다. 설문 응답의 측정 오차와 주관성이 내재되어 있어 AUC 0.65 수준은 이 조건에서 일반적인 범위입니다. 이 환경에서 Recall 85.21% + Overfit Gap 0.0066 달성이 본 모델의 핵심 성과이며, 5개 모델 중 XGBoost가 가장 균형 잡힌 성능을 보였습니다.

⚙️ 핵심 기술 의사결정

① 복합표본 가중치를 통계 검정 + 모델 학습 모두에 적용
문제

층화집락추출 데이터 → 관측값 독립 가정 위반 → 일반 분석 시 모집단 왜곡

판단

Rao-Scott 보정(통계) + XGBoost sample_weight 파라미터(모델) + WeightedStandardScaler 직접 구현(스케일링)

결과

전 분석 단계에서 복합표본 가중치 일관성 있게 반영 → 전국 청소년 모집단 대표성 확보

② Rao-Scott 카이제곱 검정 직접 구현 (scipy 내장 미제공)
문제

일반 chi2_contingency는 독립 단순 표본 가정 → 복합표본에 부적합, 1종 오류율 왜곡

판단

n_eff = W²/Σw² → DEFF 산출 → X²·자유도 동시 보정하는 Rao-Scott 함수 직접 작성

결과

스마트폰 의존·수면의 질 ↔ 구강 증상 연관성 신뢰도 있게 검증 (p < 0.001)

③ SMOTE + TomekLink 조합으로 클래스 불균형 처리
문제

구강 증상 유/무 클래스 불균형 → SMOTE만 쓰면 결정 경계 근처 합성 샘플 생성 → 경계 흐림

판단

SMOTE(소수 클래스 오버샘플링) + TomekLink(경계 노이즈 제거) 조합

결과

결정 경계 선명화 → Recall·Precision 동시 안정화

④ Optuna TPE + Youden's Index 이중 최적화
문제

Grid Search 탐색 한계 / 고정 임계값 0.5는 헬스케어 부적합 (위음성이 위양성보다 치명적)

판단

Optuna TPE 베이즈 최적화 30 Trials + 5-Fold Stratified CV / Youden's J = max(TPR - FPR) 임계값 자동 산출

결일

XGBoost Recall 85.21% 달성 + Overfit Gap 0.0066으로 과적합 최소화

⑤ WeightedStandardScaler 직접 구현
문제

sklearn StandardScaler는 가중치 미지원 → 단순 평균·분산 계산으로 모집단 왜곡

판단

가중평균 μ = Σ(w·x)/Σw, 가중분산 σ² = Σ(w·(x-μ)²)/Σw 직접 구현

결과

스케일링 단계에서도 복합표본 가중치 일관성 있게 반영
